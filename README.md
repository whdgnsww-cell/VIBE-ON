# SOLO PARTY PRO — 모바일 솔로파티 운영용 MVP

참가자는 앱 설치 없이 QR/URL로 접속합니다. 관리자만 참가자 닉네임, 작성 내용, 개별 투표 기록, 득표 순위, 상호 선택 매칭을 볼 수 있습니다.

## 핵심 흐름
1. 관리자 `/admin` 로그인
2. 새 파티 생성 → 파티별 QR 자동 생성
3. 참가자 QR 스캔 → 명찰번호 + 닉네임으로 체크인
4. 관리자가 `프로필 작성` 단계 오픈
5. 참가자는 자기 정보/질문 답변 작성 (관리자만 열람)
6. 관리자가 `투표 진행` 단계 오픈
7. 참가자는 상대방의 **명찰번호**를 1~3순위(설정 가능)로 입력
8. 관리자가 `마감` → 관리자 화면에서 상호 선택/득표/개별 기록 확인 및 CSV 저장

## 왜 명찰번호 방식인가
참가자에게 닉네임 목록을 보여주지 않으면서 현장에서 특정 상대에게 투표하려면, 명찰에 적힌 짧은 번호(A17, B04 등)를 사용하는 방식이 가장 단순합니다. 관리자는 번호와 닉네임의 매핑을 볼 수 있지만 참가자는 전체 목록을 볼 수 없습니다.

## 로컬 실행
```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt

# 관리자 비밀번호 변경 권장
# Windows PowerShell: $env:ADMIN_PASSWORD="원하는비밀번호"
# macOS/Linux: export ADMIN_PASSWORD="원하는비밀번호"
python app.py
```
브라우저에서 `http://127.0.0.1:5000` 접속. 관리자: `http://127.0.0.1:5000/admin`

## 실제 행사 배포
Render/Railway/Fly.io 같은 Python 웹 호스팅에 올리고 `ADMIN_PASSWORD`와 `SECRET_KEY` 환경변수를 설정하세요. 무료/저가 호스팅은 저장소가 재시작될 때 SQLite 데이터가 사라질 수 있으므로 실제 운영에서는 영구 디스크 또는 PostgreSQL 사용을 권장합니다.

## 보안/개인정보 메모
- 참가자 결과 조회 라우트가 없습니다.
- 관리자 결과 페이지는 세션 인증 후 접근합니다.
- 닉네임/프로필/투표는 공개 화면에 렌더링하지 않습니다.
- 실제 유료/대규모 행사에서는 HTTPS, 강한 관리자 비밀번호, CSRF 보호, DB 백업, 개인정보 보유기간/삭제정책을 추가하세요.
